# HARTH calibration episode protocol

This is a bounded fixture and protocol, not a scientific result.

1. Obtain HARTH only from the UCI URL in `data/manifest.json`; record retrieval time, URL, byte count and SHA-256. Do not commit raw data.
2. Freeze subject IDs and the test cohort in `episode.json` before inspecting results. The split is subject-held-out; windows from a subject never cross train/test.
3. Use the deterministic CPU nearest-centroid baseline. Any intervention is bounded, pre-registered, and fit only on training subjects.
4. Report NLL, multiclass Brier score, and top-label ECE with 10 equal-width bins on [0,1]. Report percentile bootstrap 95% CIs with 2,000 resamples and seed 0.
5. Run leakage checks on subject IDs and input provenance before metrics. A failed check is a preserved failure, not a retry with a changed split.
6. Preserve failed, rejected, and inconclusive run records under `artifacts/`; never rewrite them as successes. No claim, paper, or final conclusion is generated by this episode.

Synthetic fixtures in tests are pipeline-only and must not be cited as HARTH evidence.
